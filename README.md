# E-Commerce Store

A modern and scalable e-commerce frontend built with Next.js, React, TypeScript, and Tailwind CSS.

This project is a frontend redevelopment of an existing e-commerce store originally built using the Salla SaaS platform.

The goal was to transform the original storefront into a more modern, maintainable, responsive, and scalable frontend application while keeping the core e-commerce experience.

---

## 📌 Project Overview

The original store was created using Salla, an e-commerce SaaS platform.

I rebuilt the storefront from the frontend side with a focus on:

- Clean and maintainable code
- Component reusability
- Responsive design
- Type safety with TypeScript
- Scalable project structure
- State management using React Context
- Better user experience
- Preparing the application for future backend integration

The project currently works with local product data and simulated order submission, but its structure is designed to allow integration with a real backend/API in the future.
